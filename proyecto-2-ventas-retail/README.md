# Project 2 — Retail Sales Analysis (SQL + Python)

**What it shows:** business SQL queries + exploratory analysis in Python — the two skills most Data Analyst postings ask for.

**Files:**
| File | What it is |
|---|---|
| `retail_sales.csv` | 5,000 sales orders (2023–2025). Synthetic data generated for portfolio. |
| `retail.db` | Same data in SQLite, table `orders` — ready for SQL practice. |
| `consultas.sql` | 10 business queries: sales by category, margins, monthly trend, average ticket, top customers, anomaly detection, year-over-year. |
| `analisis_ventas.py` | Python EDA (pandas + matplotlib): cleaning, validation, 4 charts. |
| `eda_ventas.png` | Charts generated by the script. |

**How to run it:**
1. `pip install pandas matplotlib`
2. `python analisis_ventas.py` → console summary + `eda_ventas.png`.
3. For SQL: open `retail.db` in [DB Browser for SQLite](https://sqlitebrowser.org/) (free) and run the queries from `consultas.sql` one by one.

**Key findings (use in interviews):**
- Overall margin 16.3%; Office Supplies has the best margin (**27.9%**) with the lowest sales → opportunity to push the most profitable category.
- Furniture sells the most ($1.83M) at the thinnest margin (12.0%) → review pricing or costs.
- Average ticket even across segments (~$885–$916).

**Typical interview questions (practice in English):**
- **"How did you check data quality?"** → nulls, OrderID duplicates, date ranges, negative profits.
- **"What business recommendation would you make?"** → push Office Supplies, review Furniture pricing.
- **"Walk me through a complex query."** → explain #7 (low margin + high sales with HAVING).
