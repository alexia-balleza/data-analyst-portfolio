## Cómo publicar en GitHub (30 minutos, una sola vez)
1. Crea una cuenta en [github.com](https://github.com) (gratis).
2. **New repository** → nombre: `data-analyst-portfolio` → público → Create.
3. **Add file → Upload files** → arrastra las dos carpetas completas → Commit.
4. Edita el README principal del repo y pega la tabla de arriba.

## Cómo lucirlo
- **En el CV:** se agregará la sección "Selected Projects" con estos dos proyectos (los enlaces de GitHub se agregan cuando se publiquen).
- **En LinkedIn:** sección *Featured* → enlaza el repositorio; en *Projects* agrega cada proyecto con su descripción.
- **En entrevistas:** abre el dashboard y el gráfico `eda_ventas.png` y cuenta la historia: *qué preguntaba el negocio → qué hiciste → qué encontraste → qué recomiendas*.
