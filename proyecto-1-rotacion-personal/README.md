# Project 1 — Employee Attrition Dashboard (Power BI)

**What it shows:** end-to-end HR analytics — the People Analytics / HR Data Analyst niche.

**Files:**
| File | What it is |
|---|---|
| `hr_attrition.csv` | 1,470 employees, 14 columns (department, role, income, overtime, satisfaction, tenure…). Synthetic data. |
| `hallazgos_rotacion.png` | Key-findings chart preview (reference for the Power BI build). |
| `guia-powerbi.md` | Step-by-step build guide in Spanish: Power Query import, 5 DAX measures, 1-page dashboard layout. |
| `diccionario-de-datos.md` | Data dictionary (Spanish). |

**Key findings (use in interviews):**
- Overtime → **14.5%** attrition vs **6.0%** without overtime (2.4x) → recommend workload review for high-risk groups.
- Sales department highest at 9.3%; Sales Representative role at 11.8%.
- Lower job satisfaction → higher attrition; leavers skew toward lower income + shorter tenure.

**Status:** dataset + guide ready; dashboard to be built in Power BI Desktop (4–6 hrs, part of the Microsoft Power BI Data Analyst course).
